# section-divider

This archetype defines a large section title with an optional section number, used to mark a transition between major parts of a deck. Use this archetype in the HTML source by setting `data-archetype` on the slide section; convert that HTML directly or provide it with optional `presentation-package.json` metadata.

Use this layout sparingly — once per major section. Keep the divider visually quiet relative to the cover; the divider exists to signal a pause, not to compete for attention.
