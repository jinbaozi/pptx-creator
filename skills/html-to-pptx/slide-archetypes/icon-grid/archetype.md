# icon-grid

This archetype defines a grid of icon-plus-label tiles, typically arranged 3x2 or 2x4. Use this archetype in the HTML source by setting `data-archetype` on the slide section; convert that HTML directly or provide it with optional `presentation-package.json` metadata.

Use this layout when 6-8 items share equal weight and each fits a single icon-label pair. If items need longer descriptions, fall back to a bullets-list or two-column.
