# quote

This archetype defines a large pull-quote slide with attribution. Use this archetype in the HTML source by setting `data-archetype` on the slide section; convert that HTML directly or provide it with optional `presentation-package.json` metadata.

Use this layout when one statement deserves the full slide. Pair with attribution that names the speaker (or source) and their role. Do not use this layout for ordinary claims that fit a bullets-list.
