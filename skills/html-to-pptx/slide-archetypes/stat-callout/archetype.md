# stat-callout

This archetype defines a single hero metric plus supporting text (one big number per slide). Use this archetype in the HTML source by setting `data-archetype` on the slide section; convert that HTML directly or provide it with optional `presentation-package.json` metadata.

Use this layout when a single number is the entire point of the slide. Multi-metric rows belong in the numbers-row content pattern (which composes stat-callout horizontally).
