# toc

This archetype defines a table-of-contents slide that lists section titles with optional page anchors. This package is HTML/replica adapter metadata selected through `data-archetype`; creative text uses the compiled `deck.plan.json` registry.

Use this layout when the deck needs an early orientation slide that previews the upcoming section flow without becoming a duplicate of the cover. Keep entries short, mutually exclusive, and reflective of the actual section titles.
