# toc

This archetype defines a table-of-contents slide that lists section titles with optional page anchors. Use this archetype in the HTML source by setting `data-archetype` on the slide section; convert that HTML directly or provide it with optional `presentation-package.json` metadata.

Use this layout when the deck needs an early orientation slide that previews the upcoming section flow without becoming a duplicate of the cover. Keep entries short, mutually exclusive, and reflective of the actual section titles.
