# bullets-list

This archetype defines a single-column bulleted list of points (4-7 items). Use this archetype in the HTML source by setting `data-archetype` on the slide section; convert that HTML directly or provide it with optional `presentation-package.json` metadata.

Use this layout when a single claim needs 4-7 supporting points that share the same weight. No icons are required; if used, every bullet must carry the same icon treatment.
