# Visual design and layout selection

## Design tokens

Keep fonts, type scale, colors, spacing, radius, shadow, and grid in `design-tokens.json`. Start from `assets/design-tokens.default.json`; override only tokens supported by the plan contract. Use at most two font families. Keep body/background contrast at 4.5:1 and large text at 3:1 or higher.

## Visual translation

Choose the visual container that best exposes the message:

- one number → `metrics`;
- trend → a supplied local chart image or a clearly structured timeline until a native chart contract exists;
- category comparison → `comparison`;
- composition → explicit grouped metrics or supplied chart evidence;
- ordered steps → `process`;
- evolution → `timeline`;
- abstract concept → `statement`, `bullets`, or a supplied local diagram;
- atmosphere → `image`;
- definition or quotation → `quote`.

Do not add decorative icons, gradients, shadows, or diagrams that do not strengthen the conclusion. Do not invent chart values. A visual recommendation may remain Host-authored when deterministic rendering cannot express it safely.

## Layout invariants

- Use one `.pptx-slide` per 1280×720 canvas.
- Preserve one stable margin/grid system and a footer-safe band.
- Prefer flex/grid; reserve absolute positioning for the canvas, bounded decorations, and connector SVG.
- Keep images proportional with `object-fit: contain|cover` and explicit focal position.
- Give each major editable element `data-pptx-id` and `data-pptx-kind`.
- Mark top-level collision modules with `data-qa-box`.
- Use only local relative resources.
- Keep notes in hidden `<aside class="speaker-notes">`.

Mobile is a scaled reading surface, not a content reorder. It must preserve slide order, avoid horizontal scrolling, and keep navigation operable. Print displays every slide at the canonical size with controls and notes hidden.

## Density and type floors

The bounded repair levels never cross:

- slide title: 38px (about 28.5pt);
- card/section title: 24px (18pt);
- body/list: 22px (about 16.5pt);
- label: 15px;
- source: 12px (9pt).

When these floors cannot fit, return to the Host: shorten, split, change the visual form, or move secondary detail to notes.

## Connectors and media

Process connectors are SVG paths with source and target IDs. Runtime code anchors each path from the source right edge to the target left edge after layout. QA checks endpoint attachment, direction, marker presence, and crossing of unrelated modules.

Every image must load, have natural dimensions, include non-empty alt text, and use `contain` or `cover`. `fill` stretching is rejected. A full-slide bitmap is not generated by this Skill.
