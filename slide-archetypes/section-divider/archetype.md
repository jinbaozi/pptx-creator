# section-divider

This archetype defines a large section title with an optional section number, used to mark a transition between major parts of a deck. This package is HTML/replica adapter metadata selected through `data-archetype`; creative text uses the compiled `deck.plan.json` registry.

Use this layout sparingly — once per major section. Keep the divider visually quiet relative to the cover; the divider exists to signal a pause, not to compete for attention.
