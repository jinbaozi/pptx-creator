# icon-grid

This archetype defines a grid of icon-plus-label tiles, typically arranged 3x2 or 2x4. This package is HTML/replica adapter metadata selected through `data-archetype`; creative text uses the compiled `deck.plan.json` registry.

Use this layout when 6-8 items share equal weight and each fits a single icon-label pair. If items need longer descriptions, fall back to a bullets-list or two-column.
